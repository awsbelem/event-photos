Web assets for the gallery and the upload page, inlined into the pages by `src/event_photos/brand.py`.

- `hex-left.webp`, `hex-right.webp`: the hexagon cubes in the top corners, cut from
  `assets/frames/aws-community-day-belem/header.png` (official event artwork), boxes (0,0,84,152) and (900,0,1080,164).
- `skyline.webp`: `assets/frames/aws-community-day-belem/footer.png` (Belém skyline and sun), re-encoded.
- `fonts/inter-latin.woff2`: Inter, variable weight 400–800, Latin subset, from Google Fonts (v20).
  SIL Open Font License 1.1. Stands in for the typeface of the official artwork until the organizers confirm it.

All of them sit on the artwork's navy (#091B33), which is the page background, so they need no transparency.
The logo is `assets/brand/cd-norte/logo.svg`, used as is.
